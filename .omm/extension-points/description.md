SilverBullet's dual extension systems. (1) PlugOS: plugs define their capabilities via a .plug.yaml manifest declaring which hooks they implement. 8 hook types: Command (register keyboard-invokable commands), SlashCommand (register /slash completions), CodeWidget (implement #use/#eval directives), DocumentEditor (register custom editors for non-markdown files), Event (subscribe to events like page:index, editor:pageLoaded), MQ (message queue pub/sub), PlugNamespace (file access patterns for namespace-restricted plugs), Syscall (register custom syscalls). Plugs run in isolated Web Workers bridged by syscalls. (2) Space Lua: interpreted Lua scripts embedded in Markdown pages for live templates, widgets, and configuration — not plug-based, runs in the main thread.
