Client-side UI state transitions managed by the reducer pattern (client/reducer.ts). The AppViewState is a single immutable state object updated via dispatch(action). States include: boot (initialization), loading (page content being loaded), editor-ready (page loaded into CodeMirror), editing (user is typing), saving (auto-save throttle triggers write to server/spaces), navigating (user clicks a link or URL changes), syncing (service worker syncs files), idle (no pending changes). The reducer handles unsaved-changes tracking, command palette open/close, and notification display.
