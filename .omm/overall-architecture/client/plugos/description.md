Plug operating system (client/plugos/). The extension framework that loads and runs Plugs in isolated Web Workers. System (system.ts) manages plug lifecycle, hook registration, and syscall dispatch. Hooks (hooks/) define 8 extension points: Command, SlashCommand, CodeWidget, DocumentEditor, Event, MQ, Syscall, PlugNamespace. Syscalls (syscalls/, 23 files) bridge plug code to browser APIs: editor, space, system, datastore, markdown, shell, fetch, lua, config, mq, sync, etc. Sandboxes (sandboxes/) provide Web Worker isolation.
