Service worker internals (client/service_worker/ + client/service_worker.ts). The service worker runs in a separate browser context to provide offline-first functionality. proxy_router.ts intercepts fetch requests and routes them: serves cached client assets, proxies API calls to the sync server, handles offline caching. sync_engine.ts manages IndexedDB-based file storage and sync in the SW context. service_worker.ts is the entry point registered by boot.ts.
