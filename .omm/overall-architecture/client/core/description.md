Orchestration layer (client/client.ts ~1400 lines plus client_system.ts, content_manager.ts, editor_commands.ts, navigator.ts, space.ts, config.ts). The Client class is the central nervous system: manages the CodeMirror editor view, page navigation via PathPageNavigator, command execution, widget rendering, click/link handling, and all high-level editor interactions. ClientSystem wires PlugOS with hooks and syscalls. Config validates JSON Schema-based settings. This is a known refactoring target due to its size and scope.
