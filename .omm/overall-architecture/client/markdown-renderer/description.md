Markdown-to-HTML rendering (client/markdown_renderer/, 7 files). Converts SilverBullet parse trees to HTML for preview and non-editor contexts. markdown_render.ts handles the main parse-tree-to-HTML transformation. inline.ts renders inline elements (bold, italic, links, code). html_render.ts handles embeds, widgets, and special elements. result_render.ts formats query/Lua expression results as HTML output.
