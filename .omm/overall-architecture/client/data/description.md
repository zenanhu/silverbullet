Data persistence layer (client/data/, 15 files). Provides a key-value abstraction (KvPrimitives) with multiple backends: IndexedDB (indexeddb_kv_primitives), in-memory (memory_kv_primitives), and AES-GCM encrypted (encrypted_kv_primitives). DataStore builds a higher-level API with JSON-path get/set and prefix queries. DataStoreMQ implements async pub/sub messaging on top of the data store. ObjectIndex maintains an in-memory object cache. DataAugmenter adds computed fields.
