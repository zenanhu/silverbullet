Browser-based web application (client/). Built with TypeScript, Preact UI, and CodeMirror 6. The main orchestrator is the Client class (client.ts ~1400 lines), which manages the editor, page navigation, widget rendering, slash commands, and click handling. The boot sequence (boot.ts) loads configuration from a CONFIG page, sets up encryption, registers the service worker, and creates the Client. PlugOS loads extension "Plugs" in isolated Web Workers bridged by syscalls. A custom Lua runtime (space_lua/) interprets Space Lua scripts embedded in Markdown pages. Files sync to IndexedDB via a service worker for offline access.
