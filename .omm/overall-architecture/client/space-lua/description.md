Custom Lua runtime for Space Lua scripting (client/space_lua/, 46 files). Includes a Lezer-based parser (parse.ts, lua.grammar), AST node definitions (ast.ts), and an evaluator (eval.ts, runtime.ts) implementing the full Lua language. Standard library (stdlib/, 28 files) provides: crypto (SHA, AES), encoding (base64, hex), string (pattern matching, pack/unpack), table, math, os (time, date), net (HTTP), format (printf), and space-lua specific functions for page/queries. Used for live templates, widgets, queries, and configuration embedded in Markdown pages via space-lua fenced code blocks.
