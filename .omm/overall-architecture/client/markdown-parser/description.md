Custom Markdown parser (client/markdown_parser/, 13 files). Built on Lezer grammar system with SilverBullet-specific extensions: wikilinks, hashtags, tasks, frontmatter, fenced code, HTML blocks, admonitions, footnotes, Lua directives, and custom syntax hooks for plugs. parser.ts is the main entry point that parses markdown text into a Lezer parse tree with custom highlight tags. parse_tree.ts provides traversal utilities.
