Space primitives and sync engine (client/spaces/, 15 files). Implementations of the space storage abstraction for the client: HttpSpacePrimitives (remote server via sync API), DataStoreSpacePrimitives (IndexedDB-backed), FileSystemAccessSpacePrimitives (local disk via File System Access API). Includes EventedSpacePrimitives (event-emitting wrapper), FilteredSpacePrimitives (path prefix filter), CheckedSpacePrimitives (validation), and the SyncEngine (bidirectional sync between two SpacePrimitives, e.g. IndexedDB ↔ HTTP server).
