Chrome configuration (server-runtime-chrome/src/config.rs). Resolves the Chromium executable path and runtime settings from environment variables: SB_CHROME_PATH (binary path override), SB_CHROME_SHOW (headed mode for debugging), SB_CHROME_LOG_CONSOLE, SB_CHROME_DATA_DIR (user data directory, defaults to .chrome-data in space folder). Returns None when SB_RUNTIME_API is disabled or space is read-only. Platform-specific binary discovery for macOS, Windows, and Linux.
