Browser lifecycle manager (server-runtime-chrome/src/supervisor.rs). A long-lived async task that owns the chromiumoxide Browser and Page. Key functions: supervise() (main loop with lazy launch via Notify, liveness checks every 2s, exponential backoff on failure capped at 120s), launch_once() (builds browser config, launches Chromium, navigates to /?headless=1&token=..., attaches console capture to the shared LogBuffer, polls sbRuntime.ready for up to 60s), eval_on_page() (async JS evaluation), page_is_alive() (liveness check via trivial sync eval).
