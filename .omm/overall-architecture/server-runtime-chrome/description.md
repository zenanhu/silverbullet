Headless Chrome runtime backend (server-runtime-chrome/). Implements the ClientTransport trait from the server crate, enabling server-side Lua evaluation in a headless browser. Launches Chromium via chromiumoxide (Chrome DevTools Protocol), navigates to the SilverBullet client page with a headless token, and evaluates Lua expressions synchronously. The supervisor.rs manages browser lifecycle (lazy launch, liveness checks, exponential backoff reconnect). Console logs are captured and stored in a shared ring buffer for retrieval via /.runtime/logs.
