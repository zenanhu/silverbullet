ChromeTransport facade (server-runtime-chrome/src/transport.rs). Implements the ClientTransport trait from the server crate. Creates an owned multi-thread Tokio runtime, spawns the supervisor async task, and provides synchronous eval_js/wait_ready/is_ready methods. eval_js acquires the shared Live slot (browser+page), calls eval_on_page with a timeout, and maps CDP errors to RuntimeError. wait_ready polls a ready AtomicBool. The Drop impl calls rt.shutdown_background() to gracefully tear down the owned runtime.
