CLI argument parsing (bin/sb/src/cli.rs, ~235 lines). Defines the full CLI surface using clap derive macros. Top-level Cli struct with GlobalFlags (--space, --url, --token, --timeout, --json, --text, -o). Commands: eval (Lua expression), script (Lua script from file/stdin), query (SLIQ expressions), get (kubectl-style object retrieval), describe (schema introspection), logs (server console with --follow), repl (interactive REPL), upgrade/upgrade-edge, space (add/ls/rm named connections).
