HTTP API methods (bin/sb/src/api.rs, ~521 lines). Implements all server calls as methods on SpaceConnection: eval_lua (POST /.runtime/lua), eval_lua_script (POST /.runtime/lua_script), logs (GET /.runtime/logs), objects_raw (GET /.runtime/objects), config (GET /.config), ping (GET /.ping), probe (unauthenticated config check), auth_check. Parses the {result, error} JSON envelope from the runtime API and maps HTTP statuses.
