Connection resolver (bin/sb/src/conn.rs, ~395 lines). Manages SpaceConnection — a binding of a reqwest blocking client to a server base_url with authentication. Supports Bearer token and JWT cookie auth. login_for_jwt() POSTs credentials to /.auth, parses the auth_* cookie from Set-Cookie. Resolution order: --url directly, or look up named space in config and decrypt stored credentials. Handles re-authentication on 401.
