Space configuration persistence (bin/sb/src/config.rs, ~618 lines). Manages ~/.config/silverbullet/config.json on the user's machine. Defines Config (list of SpaceConfig entries), SpaceConfig (id, name, url, auth method, folder_path), and AuthConfig (method + encrypted tokens/passwords). XDG-aware directory resolution. Load/save with atomic file writes, 0600/0700 permissions. UUID v4 generator for space IDs.
