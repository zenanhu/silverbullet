CLI client binary (bin/sb/). Communicates with a SilverBullet server over HTTP to provide terminal access. Commands include: eval (Lua expression evaluation), script (Lua script execution), query (SLIQ queries), get (object retrieval, kubectl-style), describe (schema introspection), logs (server console log streaming with --follow), repl (interactive Lua REPL), space (manage named space connections), upgrade (self-update). Uses clap for argument parsing, reqwest for HTTP, rustyline for the REPL. Authentication supports bearer tokens and JWT session cookies with on-disk credential encryption.
