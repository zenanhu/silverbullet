Composite storage primitives (server-common/src/space/embed.rs). Three types in one file: ReadOnlyDirSpacePrimitives serves the client bundle and base_fs from disk with compile-time timestamps for cache stability. FallthroughSpacePrimitives layers two SpacePrimitives (primary + fallback) — reads try primary then fallback, writes go to primary, writes to fallback-only paths are rejected. EmptySpacePrimitives is a null object returning NotFound for everything.
