Core types and traits (server-common/src/types.rs). Defines FileMeta (file metadata with timestamps, size, MIME type, permissions), BootConfig (startup configuration sent to client via /.config), SpaceError (NotFound, PathOutsideRoot, Unauthorized, WriteError, Io), and the SpacePrimitives trait (fetch_file_list, get_file_meta, read_file, write_file, delete_file). All storage backends implement this trait.
