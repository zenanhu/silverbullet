Credential encryption (server-common/src/crypto.rs). AES-256-GCM encryption for storing credentials on disk. On-disk format: base64(iv):base64(tag):base64(ciphertext). encrypt_with_key()/decrypt_with_key() handle the colon-separated format. load_or_create_key() manages a 32-byte key file at <config_dir>/key (0600 permissions). Used by the sb CLI, desktop app, and server for credential persistence. Cross-impl tested against the historical reference format.
