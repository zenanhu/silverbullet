Self-upgrade engine (server-common/src/upgrade.rs). Downloads platform-specific release zips from GitHub Releases (stable or edge channel), extracts the binary with zip-slip protection, sets 0755 permissions on Unix. Uses reqwest::blocking (synchronous, called before Tokio runtime starts). Shared by both the sb CLI and the silverbullet server binary. upgrade.rs maps Rust's OS/arch constants to the release archive naming convention.
