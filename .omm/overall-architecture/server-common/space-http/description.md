Remote HTTP storage (server-common/src/space/http.rs). Implements SpacePrimitives by making HTTP requests to a SilverBullet server. Used by the sb CLI client and sync engine. Supports bearer token and JWT cookie authentication. Includes automatic re-authentication on 401/403 via credential exchange. Metadata parsed from X-Last-Modified, X-Created, X-Content-Length, X-Permission headers. Uses reqwest blocking client called from a dedicated sync thread.
