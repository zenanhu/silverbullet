Shared Rust crate (server-common/). Defines the core abstractions used by both the server and CLI client. Central trait SpacePrimitives with 5 methods (fetch_file_list, get_file_meta, read_file, write_file, delete_file). Multiple implementations in space/: disk (filesystem), http (remote server), memory (testing), readonly (decorator), and composite (FallthroughSpacePrimitives). Also contains types.rs (FileMeta, BootConfig, SpaceError), crypto.rs (AES-256-GCM credential encryption), and upgrade.rs (self-upgrade engine downloading GitHub releases).
