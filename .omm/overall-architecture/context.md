SilverBullet is deployed as a single statically-linked Rust binary (or Docker container). Users access it via a browser. The server serves both the SPA client bundle and a file-level REST API for the space. An optional CLI client (sb) provides terminal access. Configuration is environment-variable driven (SB_* prefix). Content is plain Markdown files on the host filesystem. No external database is required — all client-side state lives in IndexedDB.
