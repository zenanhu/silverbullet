Public API for SilverBullet plug authors (plug-api/, published to NPM as @silverbulletmd/silverbullet). Contains typed syscall wrappers (17 domain modules: editor, space, system, datastore, markdown, shell, fetch, lua, config, mq, sync, etc.) that call globalThis.syscall() to bridge plug code (in Web Workers) to the main thread. Includes reusable utility libraries (lib/: tree walking, ref parsing, crypto, dates, YAML patching, promise utilities), shared TypeScript types (types/: FileMeta, PageMeta, AppEvent, Manifest), and a Preact UI component kit (ui/: Button, Input, Select, Tabs, Alert, Badge, Progress).
