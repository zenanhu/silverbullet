Reusable utility library for plug authors (plug-api/lib/, 14 modules). Provides pure utility functions: tree.ts (ParseTree walking/transformation), ref.ts (page reference parsing with path/position/anchor), crypto.ts (SHA-256, AES-GCM/CTR, key derivation), json.ts (deep equality, date cleaning, YAML frontmatter parsing), yaml.ts (surgical YAML patching with comment preservation), async.ts (throttle, timeout, PromiseQueue, batching), dates.ts, resolve.ts (path resolution), tags.ts, transclusion.ts (wiki-link/markdown-link transclusion parsing), limited_map.ts (LRU with TTL), memory_cache.ts, shortcut.ts (keyboard shortcuts with macOS symbols).
