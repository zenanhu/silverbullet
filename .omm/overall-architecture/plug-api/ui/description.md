Preact UI component kit for plug panels (plug-api/ui/, 9 files). Provides styled Preact components for rendering plug UIs in SilverBullet's iframe-based panel system: Button (with variants: default, primary, danger, icon), Input (with Enter/Escape callbacks, IME-safe), Select, Checkbox, Tabs (with aria-selected), Alert (error/warning/info), Badge, Progress (0..1 value bar). Includes cx() for class name joining, panelStyles() for generating HTML preamble with stylesheet links.
