Shared TypeScript types (plug-api/types/, 7 files). Defines the data contracts shared between plugs and the runtime: FileMeta, PageMeta, DocumentMeta, ObjectValue (indexed objects), AppEvent (all built-in event names like page:click, editor:pageLoaded, plugs:loaded), FilterOption, Notification, PanelMode, Manifest (with SilverBulletHooks union), CommandDef (with keybindings and menu placement), SlashCommandDef, KvKey/KvQuery, MQMessage.
