Graph visualization (plugs/object-graph/, 15 files). Interactive D3 force-directed graph of the object/relation network. Two modes: local explore (current page + neighbors with lazy expansion) and global page map (all pages with all relations). Features filtered by tag/label, orphan hiding, tunable force simulation parameters, sidebar with filter checkboxes, node coloring by primary tag, edge label display. Uses the index plug's relation and page data. Includes a React UI with SVG rendering.
