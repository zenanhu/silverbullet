Settings/administration panel (plugs/configuration-manager/, 26 files). Opens a modal panel with three tabs: Configuration (edit space settings via JSON Schema-generated forms), Keyboard Shortcuts (view/search/rebind command shortcuts with chord recording), Libraries (install/update/remove libraries and repositories from URIs). Persists configuration by writing Lua config statements into CONFIG.md. Libraries management uses net.readURI via Lua to fetch remote library manifests. Includes a React UI with custom hooks for state management.
