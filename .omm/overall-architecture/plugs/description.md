Built-in SilverBullet extensions (plugs/). Each plug is a self-contained bundle defined by a .plug.yaml manifest and compiled to .plug.json. Plugs run in isolated Web Workers managed by PlugOS, communicating with the main thread via syscalls. The 8 built-in plugs are: core (JSON schema definitions), editor (50+ commands for navigation, text formatting, outline ops), index (markdown parsing pipeline, object extraction, SLIQ query engine — the largest plug at 50+ files), sync (service worker sync coordination), emoji (autocomplete), image-viewer (image file viewer with pan/zoom), configuration-manager (settings/admin panel with React UI), object-graph (D3 force-directed graph visualization).
