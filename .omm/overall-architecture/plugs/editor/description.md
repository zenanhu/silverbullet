Primary UI command center (plugs/editor/, 15 files). Wires up every user-facing keyboard shortcut, menu item, and click handler. Provides ~50+ commands: navigation (wikilink clicks, history, page-under-cursor), text formatting (bold, italic, strikethrough, highlight, quote, listify), outline manipulation (move, indent, outdent, fold/unfold), page operations (delete, copy), autocompletion (page names, footnotes, fenced-code languages), Vim mode, file upload, system reload/logout, and editor statistics. Depends heavily on the index plug for page queries.
