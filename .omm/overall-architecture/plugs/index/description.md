Central data engine (plugs/index/, 50+ files). The largest and most foundational plug. Parses every markdown page into a parse tree, then runs a pipeline of indexer functions to extract typed objects: pages, items, tasks, headers, paragraphs, data blocks, relations (links/wikilinks/images), tables, space-lua scripts, space-style CSS, anchors, tags. Objects form a structured database powering autocompletion, backlinks, task tracking, the object graph, refactoring, linting, and the X-Ray diagnostic view. Also implements the SLIQ query engine, frontmatter parser, YAML syscall, and anchor resolution.
