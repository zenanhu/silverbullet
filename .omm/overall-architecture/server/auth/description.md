Authentication subsystem (server/src/auth/, 8 files). Implements JWT (HS256) based authentication with session cookies. authenticator.rs issues/verifies JWTs with a persisted signing secret. authorizer.rs defines the RequestAuthorizer trait and AuthContext. jwt_authorizer.rs verifies bearer tokens or JWT cookies. config.rs loads SB_USER/SB_AUTH_TOKEN from env. login.rs handles credential verification and JWT issuance. lockout.rs provides brute-force protection. cookie.rs derives cookie names per host. headless_token.rs adds token-based auth for headless browser access.
