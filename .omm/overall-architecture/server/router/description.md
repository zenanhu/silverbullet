Axum router construction (server/src/router.rs). Builds the main HTTP router with two route groups: protected routes (behind auth middleware: /.config, /.fs/* for file CRUD, /.shell, /.proxy/*, /.runtime/*) and open routes (/.ping, /.client/manifest.json, /.auth, /.logout, and a catch-all SPA fallback). Also builds a Prometheus metrics_router on a separate port. Provides run_blocking(), the single async↔sync seam that runs SpacePrimitives I/O on Tokio's blocking thread pool.
