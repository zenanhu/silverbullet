HTTP request handlers (server/src/handlers/, 8 files). Each file handles a specific URL prefix: fs.rs (/.fs GET/PUT/DELETE for file CRUD with Last-Modified/304 support), bundle.rs (SPA fallback serving client bundle with SSR injection for SEO), control.rs (/.ping, /.config, /.client/manifest.json), auth.rs (login/logout pages), shell.rs (/.shell POST for command execution), proxy.rs (/.proxy/* reverse proxy), runtime.rs (/.runtime/lua and /.runtime/lua_script POST), runtime_objects.rs (/.runtime/objects GET for object index queries).
