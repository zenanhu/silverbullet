HTTP server library crate (server/). Built with Rust, Axum web framework, and Tokio async runtime. Defines all HTTP routes (/.fs/* for file CRUD, /.runtime/* for Lua evaluation, /.shell, /.proxy, /.auth) organized in handlers/. Authentication uses JWT (HS256) with session cookies managed by the auth/ module. Server-side Lua evaluation goes through the runtime/ seam (RuntimeBackend trait), which delegates to a ClientTransport implementation (headless Chrome or other). Includes Prometheus metrics (metrics.rs), shell-execution policy (shell.rs), and server-side rendering for SEO (ssr.rs). The central ServerState struct (state.rs) holds all shared dependencies.
