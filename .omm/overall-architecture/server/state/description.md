Central server state (server/src/state.rs). Defines ServerState struct — the shared state for the entire HTTP server, passed via Axum's State extractor. Holds: space (SpacePrimitives), client_bundle (ReadOnlyDirSpacePrimitives), boot_config (BootConfig), auth (RequestAuthorizer), metrics (Metrics), shell (ShellConfig), and runtime_backend (Option<RuntimeBackend>). Also defines ServerVersion for reporting at /.ping.
