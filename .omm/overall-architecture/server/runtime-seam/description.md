Lua runtime seam (server/src/runtime/, 5 files). Defines the trait hierarchy for server-side Lua evaluation. backend.rs defines RuntimeBackend trait (eval_global, logs, ready). transport.rs defines ClientTransport trait (eval_js, wait_ready, is_ready) — the lower seam for transports. client.rs provides ClientRuntime<T> that implements RuntimeBackend by building sbRuntime.* JS snippets and delegating to a transport. logs.rs provides a thread-safe ring buffer (LogBuffer, 1000 entries) shared between the transport writer and the runtime reader.
