SilverBullet is a self-hosted, programmable personal knowledge base. The architecture consists of a Rust/Axum HTTP server, a TypeScript/Preact browser client, a CLI client (sb), a plugin system (PlugOS), and a custom Lua runtime (Space Lua). Files are stored as Markdown on disk; the client syncs them to IndexedDB via a service worker. Extensions are delivered as "Plugs" running in Web Workers, bridged by syscalls. Server-side Lua evaluation runs in headless Chrome via CDP.
