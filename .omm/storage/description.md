Multi-backend storage topology. SilverBullet uses a trait-based abstraction (SpacePrimitives in Rust, space_primitives interface in TypeScript) to support multiple storage backends. Server-side: DiskSpacePrimitives for filesystem storage with optional ReadOnly wrapper and Fallthrough compositing (layering base_fs on user space). Client-side: IndexedDB via DataStoreSpacePrimitives, with optional AES-GCM encryption (EncryptedKvPrimitives). FileSystemAccessSpacePrimitives for local-only mode. HttpSpacePrimitives for remote server sync. The SyncEngine performs bidirectional sync between two SpacePrimitives (typically IndexedDB ↔ HTTP). MemorySpacePrimitives is for testing. EmptySpacePrimitives is a null-object pattern.
