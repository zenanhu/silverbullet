Module dependency graph across the SilverBullet monorepo. The codebase is split into two language ecosystems: TypeScript (client, plug-api, plugs) and Rust (server, server-common, server-runtime-chrome, sb-cli, server-bin). server-common is the shared foundation crate depended on by all Rust components. plug-api is the shared TypeScript foundation depended on by both the client and all plugs. The client communicates with the server over HTTP only — there are no shared types between TypeScript and Rust. The Chrome runtime is an optional server dependency used for server-side Lua evaluation.
