Frontend page routing and navigation structure. SilverBullet is a single-page application with client-side routing via browser History API. The PathPageNavigator (client/navigator.ts) manages pushState/popState for page navigation, tracking open locations with scroll positions and selection. Navigation entry points: wikilinks in editor, command palette (Ctrl+K fuzzy search), anything picker (unified page/command search), URL bar direct entry. The index page (default: index.md) is the landing page. Auth redirects to the server-rendered login page. Configuration opens the CONFIG.md page. No traditional route definitions — every path maps to a Markdown page in the space.
