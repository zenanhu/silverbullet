CLI command hierarchy. Three entry points: (1) silverbullet — the server binary with version, upgrade, and serve subcommands. Default starts the HTTP server. (2) sb — the CLI client with eval (Lua expression evaluation), script (Lua script execution), query (SLIQ queries), get (kubectl-style object retrieval with --selector, --where, --sort-by, --limit, --offset), describe (schema introspection), logs (console streaming with --follow), repl (interactive REPL with .timeout, .script/.end), space (add/ls/rm named connections), upgrade (self-update). (3) plug-compile — compiles .plug.yaml manifests into .plug.json bundles via ESBuild.
