The CLI client binary (bin/sb/src/main.rs). Communicates with a SilverBullet server over HTTP. 9 subcommands: eval (single Lua expression), script (Lua from arg/file/stdin), query (SLIQ queries), get (object retrieval), describe (schema introspection with human-readable tables), logs (console streaming with --follow), repl (interactive Lua REPL with rustyline), space (add/ls/rm named space connections), upgrade (self-update from GitHub Releases).
