Headless Chrome runtime backend (server-runtime-chrome/). Evaluates Lua expressions server-side by sending CDP commands to a headless Chromium browser that has the SilverBullet client loaded. The evaluation chain: server handler → ChromeTransport.eval_js() → CDP Runtime.evaluate → headless browser JS → sbRuntime.evalLua() → return result. Managed by a supervisor with lazy launch, liveness checks, and exponential-backoff reconnect.
