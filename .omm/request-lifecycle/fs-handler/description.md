File system CRUD handler (server/src/handlers/fs.rs). Handles: GET /.fs (list files with Last-Modified/304), GET /.fs/{path} (download with X-Get-Meta for metadata-only probes), PUT /.fs/{path} (create/overwrite, supports last_modified preservation for sync), DELETE /.fs/{path} (delete files and cleanup orphaned directories). All operations delegate to SpacePrimitives via run_blocking.
