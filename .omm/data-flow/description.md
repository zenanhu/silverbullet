The data processing pipeline transforms Markdown files into interactive editor content and a structured queryable database. Markdown files are loaded via space primitives, parsed by a custom Lezer grammar into parse trees, and decorated into the CodeMirror editor for live editing. Simultaneously, the indexer pipeline (in the index plug) extracts structured objects (pages, tasks, items, links, headers, paragraphs, data blocks) from parse trees into the ObjectIndex. The SLIQ query engine queries the ObjectIndex for live templates, widgets, autocompletion, and backlinks. The markdown renderer also produces static HTML for previews and SSR.
