In-memory structured object index (client/data/object_index.ts). Built from the indexer pipeline's extracted objects. Stores typed objects (pages, tasks, items, paragraphs, links, headers, tables, data, anchors, space-lua, space-style) keyed by tag and ref. Powers the SLIQ query engine, autocompletion, backlinks, and object graph visualization. Persisted to IndexedDB and rebuilt on reindex.
