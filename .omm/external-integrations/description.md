External service integrations. SilverBullet connects to GitHub Releases for self-upgrade (downloads platform-specific zip, extracts binary). Docker images are published to Docker Hub (zefhemel/silverbullet) for containerized deployment. The /.proxy/* handler allows Space Lua scripts to make HTTP calls to external APIs via server-side proxy. The fetch syscall enables plugs to make HTTP requests (requires fetch permission). Native fetch is used by Tauri/desktop builds to bypass service workers.
